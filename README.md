# ANXIA

Descargas de ANXIA para Android.

**Instalar:** entrá en [Releases](../../releases/latest), descargá el archivo `ANXIA-x.y.z.apk` y abrilo en el teléfono.
Si Android lo pide, permití «Instalar apps de esta fuente».

**Actualizar:** la app avisa sola cuando hay una versión nueva y se actualiza desde adentro.
Tus datos se conservan: quedan solo en tu teléfono, cifrados.

ANXIA es una herramienta de autoayuda psicoeducativa. No diagnostica ni reemplaza a un profesional de salud mental.
Ante una emergencia, llamá al número de emergencias de tu país.
